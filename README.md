# Auralis

A polished, ad-free music experience with on-demand playback, offline listening, synchronized group listening ("Jam"), and excellent Android system integration.

## Features
- **Local & Personal Server Playback**: Stream from Subsonic/Navidrome servers or local files.
- **Offline Mode**: Media3-managed reliable downloads for offline listening.
- **Jam**: Synchronized group playback with WebSockets.
- **Premium UI**: Jetpack Compose, Material 3, dynamic theme palette based on album art.
- **No Ads, No Tracking**.

## Build Instructions
Since local builds are unsupported in this Termux/proot environment, APKs are generated via GitHub Actions.
Check the Actions tab on GitHub to download the latest artifact.
